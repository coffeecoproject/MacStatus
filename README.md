# MacStatus

本地 macOS 菜单栏应用，实时查看 CPU、内存、硬盘、网络和温度，以及 Claude Code、Codex 会话中正在运行的命令。Swift 6，macOS 13+，无第三方依赖、网络请求或管理员权限要求。温度读取面向 Apple Silicon。

## 构建与运行

```sh
bash Scripts/build-app.sh
open .build/app/debug/MacStatus.app
```

构建脚本使用本地临时签名（ad-hoc），不需要开发者账号。生成本机自用 DMG：

```sh
bash Scripts/build-dmg.sh
```

输出为 `dist/MacStatus.dmg`，不公证，不作为跨机器分发包。

## 使用

- 菜单栏默认显示 CPU 使用率和 CPU 温度；右键（或 Control-单击）可勾选显示 CPU、温度、内存、硬盘、网络（下载 / 上传速率，如“↓1.2M ↑35K”，单位为每秒字节数，十进制），或退出。
- 左键展开面板，点击外部或按 Esc 收起；面板底部可退出。
- 外观跟随系统浅色 / 深色。

面板顶部分“概览”“内存”“任务”三页。概览分五块，每块有主数值和细项；CPU、温度、硬盘读写、网络速率在主数值旁另有近 60 秒曲线：

| 模块 | 主数值 | 细项 |
| --- | --- | --- |
| CPU | 整机使用率 | 每核使用率（按能效核 / 性能核分组）、用户 / 系统占比、1/5/15 分钟负载 |
| 温度 | CPU 传感器最高值 | CPU 平均、GPU、固态硬盘、电池、系统散热状态 |
| 内存 | 已用占比 | App、联动、压缩、缓存构成条；交换区；系统内存压力 |
| 硬盘 | 启动卷已用占比 | 卷名、已用 / 可用 / 总量、读写速率 |
| 网络 | 下载速率 | 当前连接（如 Wi-Fi；经 VPN 等非硬件接口时注明；或未连接）、下载 / 上传速率 |

内存页顶部是内存占用与交换，下面只列可退出的 App（出现在程序坞的普通 App，访达除外），按内存占用取前 10，不到总内存 1% 的不列出（退出它们腾出的内存有限），未列出的在列表下方合计数量与占用；横条按占用最多的 App 等比显示，悬停在行上可直接退出；无法从这里操作的后台、菜单栏与系统进程不列出。

任务页列出 Claude Code、Codex 各会话中正在运行的命令（开发服务器、构建、测试、监听等，散落在各个对话里的都汇总到这里），按开始时间排列，最早的在前；每行是命令（跳过 `cd`、`export` 等准备语句后的第一条），以及所在项目、Agent、已运行时长和内存（含命令启动的全部进程）。运行它的 shell 已退出、会话不再管理但仍在运行的，标为“遗留”；遗留不等于无用，悬停说明会提示：卡住的命令可以结束，有意放在后台的服务（如本地守护进程）不要结束。悬停在行上可点“结束”，在同一行确认后向命令及其全部子进程发送正常结束信号（SIGTERM），不强制结束；鼠标停留可看完整命令。

## 刷新

指标由一个时钟统一采集，只读当前看得到的：
- 面板收起：只读菜单栏勾选的指标（默认 CPU 和温度），每 3 秒一次；温度只读 CPU 传感器。
- 概览页：读全部指标和全部温度传感器（本机 67 个，其中 GPU 42 个，每个约 0.15 ms），每 2 秒一次。
- 内存页：另读内存和 App 列表，每 2 秒一次。
- 任务页：另读任务列表，每 2 秒一次。

新显示的指标在打开面板或切页的同一次更新里当场读取（计数器只需微秒级），面板以完整数据打开；需要两次采样做差的 CPU 使用率和读写速率先建立基线，0.5 秒后给出第一个值。不再显示的指标立即清空，曲线也清空，下次显示时重新开始，不会把旧值或跨越空档的差值当作当前值。系统休眠或显示器关闭时暂停，恢复后重置 CPU 与磁盘读写基线。等待下一次采样时给系统留 10% 的余量，便于和其他任务合并唤醒。面板内容只在展开时存在，收起后不再随刷新布局和绘制；数值直接更新，不做过渡动画，以免每次刷新都在 CPU 上逐帧绘制。

App 内存列表（约几毫秒）只在内存页打开时读取，任务列表（约几毫秒）只在任务页打开时读取，离开该页或收起面板时清空。面板高度随内容变化（切换页面、App 启动或退出）以短过渡动画调整，顶部保持贴在菜单栏下，内容不会上下跳动。

硬盘容量的“可用”含可清除空间，与访达一致，计算较慢（约 10ms），每 10 秒读一次；读写速率每次采样都读。网络硬件列表同样每 10 秒读一次（插拔网卡后最多 10 秒计入），速率每次采样都读。

温度经 AppleSMC 只读接口在后台单独读取，同一时间最多一个调用；结果随下一次采样一起更新，每次采样只刷新一次界面，但第一次读取或改为读全部传感器时当场显示；超过 3 秒未返回则温度显示不可用，不影响其他指标。读取失败的指标显示“—”和“不可用”标记，不会保留旧值冒充当前值。

## 数据口径

- **CPU**：`host_processor_info` 每核 `(user + nice + system) / total`；核心类型来自 IORegistry 的 `cluster-type`。
- **内存**：与活动监视器一致，已用 = App（匿名页 − 可清除页）+ 联动 + 压缩；缓存 = 文件缓存页 + 可清除页。内存显示用二进制单位，硬盘用十进制单位（与访达一致）。
- **App 内存**：`proc_pid_rusage` 的物理占用（含压缩与已换出的页，同活动监视器“内存”列）。进程按可执行文件所在的最外层 `.app` 并入所属 App；不在列出的 App 包内的，按系统记录的负责进程（`responsibility_get_pid_responsible_for_pid`，同活动监视器的归类）并入，如 Safari 的网页内容进程、Docker 的虚拟机、终端里运行的命令。该接口为私有接口，运行时查找，系统不再提供时只按所在 App 包归类。名称取 App 在 Info.plist 中声明的名称（同活动监视器）。只列正在运行的普通 App（同“强制退出应用程序”窗口，含嵌在 App 包内的，如 Docker.app 中的 Docker Desktop；访达没有“退出”，不列出）。只读当前用户的进程，无需管理员权限。“退出”效果等同在该 App 中选择“退出”，App 可能询问是否存储或拒绝退出；不提供强制退出。
- **任务**：只读当前用户的进程。Agent 的会话进程按可执行文件名认定（`claude` 为 Claude Code，`codex` 为 Codex，含 Codex App 的 `codex app-server`）；会话进程直接启动的 shell（zsh、bash、sh，或 Codex 沙盒的 `sandbox-exec`）是一个任务，它直接启动的其他程序（MCP 服务器、辅助进程）不算。shell 退出后仍在运行、被 launchd 接管的进程，按系统记录的负责进程（同 App 内存）归到仍在运行的 Agent 会话，标为“遗留”；负责进程是 App 而非会话进程时（如 Codex App、在终端里运行的 Agent）无法归属，不列出，会话进程退出后留下的也不列出。launchd 代命令里的程序启动的 XPC 服务（如浏览器用到的系统服务，程序在 `.xpc` 包内）同样归在会话名下，但不是命令自己的进程，不列出。同一进程组的遗留进程是同一条命令行留下的（如管道两侧，Claude Code 为每条命令建一个进程组），合为一个任务；还在运行的 shell 所领的组里离开该 shell 的进程并入它的任务；Agent 自身所在的进程组（如 Codex App 与其 app-server 共用的）不据以合并。命令取自进程参数（`KERN_PROCARGS2`）：shell 的 `-c` 脚本，去掉 Claude Code 的 shell 环境准备和 Codex 的沙盒包装。列表中每行显示的是其中第一条实际执行的命令：按 shell 的规则（引号内不算）在换行、`;`、`&&`、`||` 处分开，跳过 `cd`、`export`、变量赋值和注释，以路径给出的程序只显示文件名；鼠标停留显示完整命令。前台与后台命令从进程上无法区分，一并列出。项目取命令工作目录所在的 git 仓库名，worktree 归到主仓库；不在仓库中（或只在主目录这个仓库中）时取目录名，工作目录为根目录时不显示。结束前重新读取，只向仍是同一进程（pid 与启动时间都相同）的任务及其当前全部子进程发送 SIGTERM，子进程先于 shell。
- **硬盘读写**：所有块存储设备 `IOBlockStorageDriver` 统计之和。
- **网络**：系统设置里列出的网络硬件（Wi-Fi、以太网、雷雳等，`SCNetworkInterfaceCopyAll`）的收发字节数之和，逐个接口读其 MIB（`IFMIB_IFDATA`）的 64 位计数，与 `netstat -ib` 一致；`getifaddrs` 和接口列表 `NET_RT_IFLIST2` 的计数到 4 GB 即回绕，不用。不计回环、VPN 隧道（`utun*`，其流量已经过 Wi-Fi 等硬件，计入会重复）、虚拟机网卡、隔空投送（`awdl0`）以及桥接 / 绑定 / VLAN（其成员已计入）。按接口逐个求差，期间新出现或重置的接口不会被当成突增。当前连接取默认路由所在接口（`State:/Network/Global/IPv4`，无 IPv4 时取 IPv6）。不发出任何网络请求，因此不显示公网 IP。
- **温度**：启动时枚举 SMC 键，`Tp*`/`Te*` 归为 CPU，`Tg*` 归为 GPU，`TH0x` 为固态硬盘，`TB0T` 为电池；只接受 `flt` 类型，读数不在 0–150°C 之间的传感器跳过。这些键没有苹果公开的兼容性承诺，macOS 或机型变化可能导致分组失效。

## 代码结构

- `MacSystemMetrics`：各指标读取器与纯计算（CPU 差分、内存构成、读写速率、SMC 报文、温度分组汇总）。
- `MacStatus`：`SystemMonitor` 调度与 60 秒历史；AppKit 菜单栏与面板；SwiftUI 卡片视图。
